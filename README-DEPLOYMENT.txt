EXPERTS GROUP PLUS - WEBSITE PACKAGE

Contents
--------
index.html
  Public single-page website. Includes the English / Egyptian Arabic language
  switch, right-to-left Arabic layout, and the existing Google Tag Manager
  container (GTM-MQDTZHPD).

pdf/
  Five redesigned English capability profiles and five matching Arabic editions:
    - Corporate Profile
    - Training Profile
    - Consultation Profile
    - Operations Profile
    - BPO Profile

PDF downloads
-------------
All profile-download buttons use local files in ./pdf/. The selected language
controls which edition is downloaded. No client-side PDF generator is needed.

Deployment
----------
1. Extract this ZIP.
2. Upload the contents of the ExpertsGroupplus-main folder to the root of your
   existing GitHub repository, replacing the previous website files.
3. Commit and push the changes.
4. Railway should redeploy automatically if the project is connected to GitHub.

The previous Admin Portal and its private pages are not included in this package.
